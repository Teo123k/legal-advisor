# Evidence Checklist (Appendix FM-SE + guidance)

Legend: **MUST** = rule-required · **ADV** = strongly advised · **OPT** = helpful.
Every non-English/Welsh document needs a **certified translation**.

## 🪪 Identity & status
| Item | Level |
|---|---|
| Applicant's current passport (+ previous passports showing travel history) | MUST |
| Sponsor's British passport / naturalisation certificate / eVisa share code / ILR evidence | MUST |
| TB certificate (if from a listed country, entry clearance) | MUST if applicable |
| Applicant's current UK immigration status (in-country) | MUST |

## 💍 Relationship
| Item | Level |
|---|---|
| Marriage / civil partnership certificate | MUST (spouse/CP) |
| Evidence previous marriages ended (final order / decree absolute / death certificate) | MUST if applicable |
| Unmarried: evidence of ≥ 2-year relationship akin to marriage (joint tenancy, bills, bank, council tax, letters at same address; or explanation + evidence for periods apart) | MUST |
| Fiancé(e): evidence of wedding plans (venue booking, quotes, notice-of-marriage plan) | MUST |
| Photos together across time (incl. with family / at wedding) — 10–20, captioned & dated | ADV |
| Communication evidence (WhatsApp/call logs — samples across the relationship, not hundreds of pages) | ADV |
| Visits: boarding passes, passport stamps, hotel bookings | ADV |
| Joint documents if lived together (tenancy, utility bills, bank statements, council tax) | ADV |
| Children together: birth certificates | MUST if applicable |
| Personal statements from both (how met, relationship history, plans) | ADV |

## 💷 Money (pick the category — see `02-financial-requirement.md`)
| Item | Level |
|---|---|
| Payslips covering the required period (6 or 12 months) | MUST (A/B) |
| Personal bank statements showing net salary credits for same period | MUST (A/B) |
| Employer letter with all FM-SE para 2(b) items | MUST (A/B) |
| P60 for latest tax year | ADV (often required in guidance for Cat B) |
| Employment contract | ADV |
| Savings statements covering 6 months, all pages | MUST (D) |
| Source-of-funds trail for any transfer into savings | MUST if applicable |
| Self-employed: SA302s/tax calculations + tax year overviews, accounts, business bank statements, evidence of registration with HMRC | MUST (F/G) |
| Ltd company director: CT600, company accounts, Companies House, payslips/dividend vouchers, personal & business statements | MUST (F/G) |
| Non-employment income: ownership proof, tenancy agreements, statements showing receipt | MUST (C) |
| Benefit award letters (exemption route) | MUST if exempt |

## 🏠 Accommodation
| Item | Level |
|---|---|
| Tenancy agreement or mortgage statement / title (Land Registry) | MUST |
| Letter from owner/landlord consenting to applicant living there (if staying with family/friends) | MUST if applicable |
| Property inspection report (room count, occupants, not overcrowded) | ADV where shared/many occupants |
| Council tax bill / utility bill at the address | OPT |

## 🗣 English language
| Item | Level |
|---|---|
| SELT certificate at required level (unique reference number) | MUST unless exempt |
| OR degree certificate + Ecctis confirmation it was taught in English | MUST alternative |
| OR passport of majority-English-speaking country | MUST alternative |
| Medical evidence for disability exemption | MUST if claimed |

## 📜 Other
| Item | Level |
|---|---|
| **Cover letter / legal representations** with evidence index | ADV (lawyers always do this) |
| Explanations for any gaps, discrepancies, previous refusals | MUST if applicable |
| Previous refusal letters + how issues have been resolved | MUST if applicable |
| Article 8 / exceptional circumstances evidence (medical, school, country reports, expert reports) | MUST if relying on EX.1/GEN.3.x |

## Formatting rules lawyers apply
- Numbered, tabbed bundle; index on page 1; each item labelled `[A1] Passport – applicant`.
- Chronological within sections; consistent names/dates across all documents.
- Explain every discrepancy (name spellings, date formats, address changes) in the cover letter — don't
  leave the caseworker to guess.
